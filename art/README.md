# Game art

Game-ready copies of the art in `Gamedes Game Assets/`, resized to the largest size the game draws. Godot loads only this folder. The originals keep their full size for the artists and are skipped by Godot through the `.gdignore` file.

- Regulars and strangers: up to 640 px
- Entity true forms: up to 1024 px
- Shop goods and the price list: up to 512 px
- Store backgrounds: unchanged
- Main menu art: 1280 x 720

When an artist updates a file in `Gamedes Game Assets/`, copy it here at the same path and size.
